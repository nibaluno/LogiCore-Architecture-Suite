# LogiCore Architecture Suite

**LogiCore Architecture Suite** — это демонстрационный проект логистической системы, написанный на Java, основной целью которого является применение и демонстрация глубокого понимания принципов **GRASP** и **GoF (Gang of Four)** паттернов проектирования.

Проект решает задачу расчета стоимости и времени доставки грузов различными видами транспорта, предоставляя гибкие механизмы фильтрации, комбинированной сортировки и многослойного экспорта данных.

---

## Ключевые особенности

- **Мультиформатность:** Загрузка данных из файлов `CSV`, `JSON` и `XML` с использованием динамического выбора парсера.
- **Расчет логистики:** Автоматический расчет стоимости (груз + транспорт) и времени пути для всех видов транспорта (Земля, Вода, Воздух).
- **Интерактивность:** Пользователь сам формирует партию грузов и настраивает параметры обработки через консольный интерфейс.
- **Гибкая фильтрация:** Реализация цепочки проверок (скорость, цена) перед выдачей результата.
- **Комбинированная сортировка:** Возможность одновременной сортировки по нескольким критериям (например, сначала по цене, затем по скорости).
- **Многослойный экспорт:** Сохранение отчетов с возможностью «наслаивания» функций: формат файла + шифрование AES + сжатие ZIP.

---

## Архитектурные паттерны (Design Patterns)

Проект спроектирован с упором на слабую связанность (**Low Coupling**) и высокую сплоченность (**High Cohesion**).

### GoF Паттерны:
- **Facade (Фасад):** Класс `LogisticsFacade` предоставляет упрощенный интерфейс для управления всеми подсистемами проекта.
- **Abstract Factory (Абстрактная фабрика):** Создание согласованных семейств объектов (Транспорт + Накладная) в зависимости от типа доставки.
- **Decorator (Декоратор):** Позволяет динамически добавлять обязанности экспортеру (шифрование, ZIP-сжатие) без изменения базового кода.
- **Strategy (Стратегия):** 
  - Используется в `DataLoader` для выбора алгоритма парсинга.
  - Используется в `SortingProvider` для выбора алгоритмов сравнения.
- **Chain of Responsibility (Цепочка обязанностей):** Фильтры соединены в цепочку, позволяя последовательно обрабатывать результаты.
- **Iterator (Итератор):** Применяется при обходе коллекций в модулях экспорта и обработки данных.

### GRASP Принципы:
- **Information Expert:** Расчет стоимости партии груза инкапсулирован в `CargoItem`.
- **Controller:** Управление бизнес-логикой вынесено в специализированные сервисы.
- **Polymorphism:** Обработка различных типов транспорта и форматов файлов через общие интерфейсы.

## Технологический стек

- **Language:** Java 25 (использование Instance Main Methods, Text Blocks, Records).
- **File I/O:** Java NIO, Stream API.
- **Data Formats:** CSV, JSON, XML.
- **Security:** AES Encryption (javax.crypto).
- **Compression:** ZIP (java.util.zip).

---

## Как запустить

1. Убедитесь, что у вас установлена **JDK 21+**.
2. Поместите файлы данных (`logistic.csv`, `logistic.json`) в папку `src/main/resources`.
3. Запустите класс `Main`.
4. Следуйте инструкциям в консоли:
   - Введите имя файла.
   - Выберите грузы и количество.
   - Настройте фильтры и сортировку.
   - Выберите желаемые «слои» экспорта.

## Структура проекта

```text
src/org/example/
├── domain/            # DTO и доменные модели (Cargo, DeliveryResult)
├── export/            # Паттерн Декоратор (Экспорт, Шифрование, ZIP)
├── factories/         # Паттерн Абстрактная фабрика (Логистика)
├── filters/           # Паттерн Цепочка обязанностей (Фильтрация)
├── parsers/           # Паттерн Стратегия (Парсинг CSV/JSON/XML)
└── service/           # Сервисный слой и Фасад
```
